## 3. Process rule (when drafting eventually opens)

1. Fetch/read all canon source chunks for the beat.
2. Write the `canon_coverage/` record **before** prose.
3. Draft, run the chapter gate, sync STATUS the same turn, log mirrors.
4. Compress routine canon beats; expand only meaningful butterfly,
   character, tactical, or relationship changes (pacing rule learned from
   fire-phoenix — useful, adopted).
5. Present only what passed.

## 4. Authority order (high → low)

1. **The author's word** (in `RULINGS_LOG.md`, verbatim)
2. `STATUS.md` — live state
3. `NO_MISTAKE_LIVE_RULES.md` — this file
4. `OPEN_RULINGS.md` — what is still open

6. `codex`/`foundation` support files — relationships, butterflies, arcs
7. newest dated receipt — among evidence, newest wins
8. everything else — **historical evidence only**

## 5. If you find a contradiction

Report it, cite both sources and their dates, propose the minimal
correction, and wait for the author.
